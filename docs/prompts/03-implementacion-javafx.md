# Prompt 03 — Implementación JavaFX

**Rol:** instrucción técnica (derivada del requerimiento)

```
Implementa la UI en JavaFX con FXML:

1. Pantalla inicial con botón "Solicitar saludo".
2. Pantalla "Pedir datos" con nombre, edad y hora AM/PM.
3. Validación básica de los campos.
4. Pantalla de resultado que saluda por nombre y menciona la edad.
   Usa AM/PM para "Buenos días" o "Buenas tardes".

Separa modelo, servicio y controladores.
Incluye pom.xml y un script run.ps1 porque el entorno puede no tener Maven
y el JDK no incluye JavaFX.
```
