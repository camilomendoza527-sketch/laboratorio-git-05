# Prompt 04 — Documentación del proyecto

**Rol:** instrucción de documentación (derivada del requerimiento)

```
Escribe la documentación en español, clara para un curso de ingeniería:

- README de arranque.
- docs/prompts con cada prompt numerado.
- docs/reflexion/retos.md
- docs/reflexion/descubrimientos.md
- docs/reflexion/sorpresas.md

La reflexión debe ser honesta: qué fue difícil, qué se aprendió
y qué no era obvio al empezar.
```
